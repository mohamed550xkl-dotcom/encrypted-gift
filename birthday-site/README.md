# موقع عيد الميلاد 💌

## النشر على GitHub Pages
1. اعمل Repository جديد على GitHub.
2. ارفع كل محتويات الفولدر ده (index.html و style.css و script.js و images و audio).
3. من Settings > Pages اختار Branch: main و Folder: / (root) واضغط Save.
4. بعد دقيقة هيطلع لك اللينك، وتقدر تعمل منه QR code.

## الأغنية
الأغنية موجودة في فولدر audio باسم senorita.mp3

## التعديل
كل النصوص (الاسم، الكود، القصة، الكروت، الجواب) في أول ملف script.js.
